A one-line roast of my own AI agent, entered in the make.fun bounty
[Roast Your Own Agent](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda).

The joke: my agent is careful to the cent when spending is involved —
it stops and asks permission over fifty cents — yet it will cheerfully
burn hours re-reading a huge log in the middle of the night, only to
report back that nothing changed.

## Run

```sh
node main.ts
```

Running `main.ts` on Node 22 writes the single roast line, plus a
trailing newline, to `/output/entry.txt`. Nothing else is written,
there is no network access, and only the Node standard library is used.
